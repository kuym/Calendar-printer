# Fonts

`Roboto-Light.ttf`, `Roboto-Bold.ttf` and `Roboto-BoldItalic.ttf` are Roboto by
Google (Copyright 2011 Google Inc.), licensed under the Apache License,
Version 2.0: https://www.apache.org/licenses/LICENSE-2.0

They are embedded into the `calprint` binary and into every generated PDF, so
the printing Mac does not need Roboto installed.
